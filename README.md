# SUZA Lecturer Profile Card

This project is a **Lecturer Profile Card** webpage for a SUZA staff member. The page displays a lecturer photo, name with title, department, courses taught, office hours, and an email link.

## System Overview

The page is a simple academic profile system that presents important lecturer information in one responsive card. It helps visitors quickly see the lecturer's department, courses, office hours, and contact option.

## Requirements Completed

- Built with valid HTML5, including `DOCTYPE`, `lang`, `charset`, `viewport`, and page title.
- Used semantic HTML elements such as `header`, `main`, `section`, `article`, `nav`, and `footer`.
- All styles are written in `styles.css`.
- No inline CSS, no `<style>` tags, and no JavaScript.
- The lecturer card uses Flexbox to align the photo on the left and details on the right.
- The page layout uses Flexbox and CSS Grid.
- Includes at least two images with descriptive alt text.
- Includes working links, including:
  - A `mailto:` email link.
  - An external SUZA website link that opens in a new tab using `target="_blank"` and `rel="noopener noreferrer"`.
- Colours are defined using CSS custom properties.
- Hover effects are added to links and the card.
- Includes a media query so the page works well on a 375px-wide phone screen.
- The footer includes the full name, registration number, and question number.
